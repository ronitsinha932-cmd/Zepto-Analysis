# Zepto Product & Inventory Analysis

## Project Overview

This project analyzes Zepto product and inventory data using PostgreSQL.

The objective is to identify product performance, pricing patterns, discounts, inventory status, and estimated revenue opportunities through SQL-based data analysis.

## Business Objectives

- Analyze product pricing and discounts
- Identify high-value products
- Analyze stock availability
- Identify low-stock products
- Estimate revenue by category
- Analyze inventory value
- Rank products and categories using advanced SQL

## Dataset

The dataset contains product-level information including:

- SKU ID
- Product category
- Product name
- MRP
- Discount percentage
- Available quantity
- Discounted selling price
- Weight
- Stock status
- Quantity
